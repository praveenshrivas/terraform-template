# Section - 01: Terraform Templates

This section contains various Terraform templates for provisioning resources across different cloud providers and services.

---

## 📄 Template 01: Provision a Simple EC2 Instance
Create a basic EC2 instance using the AWS provider.

---

## 📄 Template 02: Provision Two EC2 Instances
Provision two EC2 instances within the same configuration using Terraform.

---

## 📄 Template 03: EC2 Instance with Azure Provider
Create an EC2 instance on AWS along with configuration for the Azure provider.

---

## 📄 Template 04: EC2 Instance with DigitalOcean Provider (Specific Version)
Provision an EC2 instance with AWS and include the DigitalOcean provider using a specific version.

---

## 📄 Template 05: Create a GitHub Repository
Use Terraform to create a new repository on GitHub.

---

## 🛠 Template 06: Destroy Resources
- **Destroy all resources**: Use `terraform destroy` to remove all infrastructure managed by the current Terraform state.
- **Destroy specific resource**: Use `terraform destroy -target <resource_type.resource_name>` to destroy a specific resource.

---

## 📄 Template 07: AWS Provider with Specific Version
Configure the AWS provider with a specific version constraint in your Terraform script.

---

## 📄 Template 08: Create IAM User
Use Terraform to create an IAM user with required attributes and policies.

---

> 💡 Each template is designed for learning and practical application. Customize according to your cloud environment and infrastructure needs.
